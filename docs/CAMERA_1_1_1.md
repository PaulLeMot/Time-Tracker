fetch/switch/pull --ff-only,99ed59e71a679f3229b733db1c8f912a511c5219; новых
upstream-коммитов на начало работы нет. Продолжение [камеры1.1](CAMERA_1_1_0.md).

## Изменения

- Удалён весь нижний абзац камеры, в том числе текст про белые поля/сохранение
  кадров. Верхний статус и обработка ошибок остаются. На узком/невысоком экране
  capture-диалог ограничен высотой экрана, предпросмотр получает оставшееся место,
  «Отмена» видна без прокрутки. Ошибка использует компактную высоту; OCR-выбор
  товара остаётся прежним диалогом, без изменения подтверждения.
- Только до700px: камера44×44 справа от поля, доступное имя сохранено, текст
  кнопки скрыт. Те же `markingDisplay`, dropdown и обработчики переносятся в строку
  после введённого ID и перед логотипом. При возврате к широкому экрану контрол
  возвращается на прежнее место без потери фильтра, состояния и ID элементов.
- Код/название, вид/фандом сохраняются ниже. Верхний отступ ID80px убран.
  Большие четыре цифры стикера и порядковый номер не переносятся посередине;
  малый префикс стикера располагается над четырьмя цифрами.
- Картинке выделено30dvh, максимум250px: на446×840 —250px вместо примерно375px.
  Пропорции и object-fit:contain сохранены. На коротком экране до740px таблица
  имеет240px, картинка180px и доступна прокруткой общей области: таблица не
  сжимается до полоски. Длинная выдача продолжает прокручиваться внутри таблиц.
  Смешанная WB/OZ-таблица из трёх колонок имеет горизонтальную прокрутку.
- Desktop маркировки не меняется: CSS новых правил ограничен мобильными media
  queries, исходный DOM фильтра восстанавливается. Логика сопоставления, renderer
  данных, история, запросы, refresh/import и права не изменены. В search.html
  меняются только версии общих scanner/CSS. Декодеры и OCR-модели прежние.

Фотографии/видео по-прежнему остаются в RAM. Масштаб браузера не запрещён:
viewport не содержит maximum-scale/user-scalable=no, touch/pinch не перехватывается.
Физический жест двумя пальцами проверяется владельцем на телефоне, не имитировался.

## Выпуск и откат

Публикация только main, поимённо проверенных файлов; fetch/pull --rebase/push,
сервер clean→fetch→switch main→pull --ff-only. После установки проверить HEAD=
origin/main, SHA256 четырёх runtime-файлов по HTTP/HTTPS, вход и безопасный
невалидный JSON POST для HTTPS redirect. ID/StartedAt/RestartCount контейнеров,
PID дочерних процессов приложения и SHA256 nginx-конфига должны сохраниться.
Не выполнять restart/reload, миграции, реальные отметки, refresh/import.
Точный SHA и результат установки фиксируются в сопровождающем отчёте выпуска.

только `static/camera-scanner.js`, `static/camera-scanner.css`, `static/mark.html`,
`static/search.html` из99ed59e71a679f3229b733db1c8f912a511c5219, проверить,
опубликовать новым коммитом и установить ff-only. Не откатывать весь репозиторий,
не менять HTTPS, службы, сеть, данные или исходники Next.
