# Поиск по фото 0.2.1, сканер 1.1.5 — 03.11.2026

Продолжение действующего этапа 2 по диктовке владельца. Вычислитель, модель,
индекс, маршруты API, роли, поиск сотрудников и данные не меняются.

В первой строке поиска: логотип, число товаров, поле кода, камера, штрихкод.
Кнопки без видимого текста, с доступными именами; одинаковый SVG штрихкода в
поиске и маркировке. Поиск по фото в маркировку не добавлен. Код карточки
увеличен на 1 CSS px, жирный, #0759e6. Единственный результат занимает обычную
левую ячейку сетки; на телефоне два столбца. Изображение 500/fallback сохранено.

Окно фото: вид товара в заголовке, симметричный крестик; нижний ряд Файл /
Следующий / Снимок→Найти, Вставить отдельным рядом. Загрузка кадра происходит
только по Найти. Следующий возвращает камеру, сохраняя вид. Масштаб/поворот
доступны для кадра; после результата скрыты. Счётчик и пастельные статусы
сохранены, сопровождающие подсказки удалены из видимого интерфейса. Кадры
остаются в RAM и освобождаются; в sessionStorage только выбранный вид.

Живая камера фото и сканера заполняет центральный квадрат через cover.
Сканер декодирует именно этот квадрат, без периодического скрытого полного
кадра. Белая рамка удалена; красная линия 1 px, reduced-motion сохранён.
EAN-13/Code128, локальный OCR с подтверждением, задняя камера, подсветка,
аппаратный масштаб и ручной ввод сохранены. Весь штрихкод должен помещаться
в видимый квадрат. Геометрия ограничена доступной высотой, кадр без внутренней
прокрутки; выдача имеет одну прокрутку.

Проверки: lab/compact-camera-browser.cjs — исходные assets, синтетическая
задняя камера 960×540, сравнение фактического JPEG и центрального квадрата,
одноэлементная сетка, порядок/состояния, 390×760, 320×480 с шрифтом22,
844×390 и1366×768. Это не приёмка физических смартфонов. Старые lab/tests.js
размещают независимую этикетку целиком в квадрате; асинхронная выдача после
OCR ожидается по DOM. mobile-tests проверяет новую линию1px и квадрат.
Результаты production и автопродления фиксируются после внедрения.

Модуль бликов/перспективы в эту версию не входит: по поручению только анализ.
